# Letrasdroid

Escucha la música que suena alrededor, reconoce la canción con Shazam y muestra su letra sincronizada, resaltando la línea que se está cantando.

Versión para Android de [Letras (Letrasios)](https://github.com/baltamir1978/Letrasios), la app de iOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Kotlin + Jetpack Compose, para **Android 12 o posterior**, también en **GrapheneOS** (sin los servicios de Google).
